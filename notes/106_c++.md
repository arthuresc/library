# C++ (e as vezes uns C)

## Sintaxe

### Arquivos .h (ou .hpp)

- São arquivos de cabeçalho que servem como arquivos para serem importados.

### `#pragma once` e `#ifndef`

- Ambos garantem a unica inclusão do arquivo em uma unica compilação.
- Apesar de ambos terem a mesma função mas sintaxes diferentes:


- O `#pragma once` é mais recente e simplificado, a maioria dos compiladores já entendem

```cpp
  #pragma once

    class Animal {
        // ...
    };
```

- O `#ifndef` consegue ser usado com compiladores mais antigos mas precisa ser finalizada

```cpp
  #ifndef ANIMAL_HPP
  #define ANIMAL_HPP

    class Animal {
    // ...
    };

  #endif // ANIMAL_HPP
  ```

## Conhecimentos

### Guardar valores: #define | const | e variaveis não inicializadas

- O `#define` vai guardar um valor, que é no final tratado como **string**,

### Como importar funções, classes, estrturas e constantes

- Crie o arquivo .h
- Use o `#pragma once` ou `#ifndef`
- Crie as funções ou o que for necessário para ser exportado


## Sobre Classe (Class)

### O que é?
  A classe é a planta, o "formato" do objeto que por sua vez é a casa.
  A classe é um TIPO, assim como _int_ descreve numeros inteiros a classe descreve um tipo de alguma coisa.

### _public:_ e _private:_

  São locais dentro da classe aonde você define o que é privado e publico (como pode ser visto em [[304_orientacao-a-objetos##Tipos de encapsulamento]] ), acontece que no c++ TUDO declarado antes de _public:_ é _private:_, logo se não colocado o _public:_ tudo é _private:_.

### Métodos
  Métodos são funções 

### Bibliotecas(Libs) e Modulos

  Arquivos .h (A promessa)
  ```c++
class Bicicleta {
private:
    int marcha;

public:
    void mudarMarcha(int novaMarcha);  // ← PROMESSA. Sem corpo. Sem { }.
};  // ← ; aqui
  ```
  Aqui eles levam somente a identificação do que a classe vai poder fazer, isso diferenciando os tipos de encapsulamento

  Arquivos .cpp (O cumprimento)

  ```c++
#include "Bicicleta.h"

// [1] Operador de ESCOPO ::  (lê-se: "pertencente a")
// void Bicicleta::mudarMarcha(int novaMarcha)  = "a função mudarMarcha,
//                                               que pertence à Bicicleta"
void Bicicleta::mudarMarcha(int novaMarcha) {
    marcha = novaMarcha;  // Directo! Porque está dentro do escopo da classe.
}
  ```

Aqui é levada a logica, se baseando em como foi descrito no arquivo .h, a lógica em si precisa dizer como o será o resultado ou as açoẽs desse método se baseando no cabeçalho.

#### Exceção: Inline
  Caso seja aberta um bloco de código `{}` dentro do cabeçalho `.h` aquele método é inline, logo será executado normalmente. Mas para isso ele precisa ter somente 1 linha.

### Regra Canonica
  Iniciar uma classe não significa que será iniciado os valores na ordem das linhas pelo compilador, mas sim na ordem canonica.
  ```c++
class Erro {
private:
    int depende;    // Declarado PRIMEIRO
    int base;       // Declarado SEGUNDO
public:
    Erro(int v) : base(v), depende(base + 1) {} // "Parece" certo
};
  ```

  Por isso o código acima daria um erro, pois o compilador cria o valor de `depende` e ao inves de iniciar o proximo valor de `base` ele já pula para a linha aonde se é dado o valor de `depende` que no caso por depender de `base` ele vem aleatório, portanto corrigido ficaria assim:

```c++
class Certo {
private:
    int base;       // Declarado PRIMEIRO
    int depende;    // Declarado SEGUNDO (depende do primeiro)
public:
    // A ORDEM AQUI DEVE IMITAR A ORDEM ACIMA
    Certo(int v) : base(v), depende(base + 1) {} // AGORA FUNCIONA
};
```
