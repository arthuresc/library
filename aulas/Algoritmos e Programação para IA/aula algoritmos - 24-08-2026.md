# Aula de aula algoritmos

## Principal

- pseudocódigo ou português estruturado por exemplo o portugol
  - é a maneira mais próxima da nossa lingua da linguagem, aonde você consegue aplicar a lógica
  - não serve para programar mas sim para se montar a lógica
  - 
- A ideia do fluxograma é uma forma visual de *desenhar* a lógica (diagrama)
  - serve para mostrar o que o seu código está fazendo
- Na hora de desenvolver nós temos 3 "bases" para construirmos a lógica
  - O código propriamente dito
  - Pseudocódigo para escrever a lógica da maneira mais proxima da lingua falada
  - Fluxograma para construir a lógica de maneira visual
