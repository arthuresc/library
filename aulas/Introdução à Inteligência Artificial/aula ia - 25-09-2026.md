## Principal

- IA, deep learning e machine learning
- Perceptron é um unico neuronio sendo usado para calcular as respostas
- Multilayer Perceptron são varios neuronios de perceptron sendo usados simultaneamente para calcular melhor a saída 
- "Componentes do neuronio"
  - Entradas: São os neuronios de entrada, São os dados informados ao modelo para analise
  - Camada de entrada: ocnjunto de nós por onde os dados iniciais entram na rede
  - Peso: é o valor constante que ajusta a tendencia padrão do neuronio
  - Soma ponderada: o resuktado que converte a soma ponderada no sinal de saida de neuronio
  - Função de Ativação: o fikltro matematica qure converte a soma ponderada no sinal de saída do neuronio
  - Saída: o resultado final gerado pelo processamento do neuronio
- **A cada epoca é realizado um Back propagation**
